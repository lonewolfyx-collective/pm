# create：从模板创建项目

`create` 交互选择模板和目标目录，然后下载模板文件。

## 用法

```bash
create
create --cwd ./apps
```

命令从 `lonewolfyx-template/starter` 仓库的 `templates` 目录获取模板定义，因此需要网络连接。模板列表以实际获取的内容为准。

## 执行流程

1. 获取模板列表，显示模板名称和描述供选择；
2. 输入目标目录，默认值来自所选模板的 `defaultDir`；
3. 将目标目录相对于工作目录解析，再下载模板。

例如，执行 `create --cwd ./apps` 后输入 `web`，会在 `./apps/web` 中创建项目。取消模板或目录选择会以非零退出码结束。

::: danger 会清空已有目标目录
如果目标目录已存在，命令会直接删除其中除 `.git` 外的所有内容，再下载模板，不会询问是否覆盖。选择 `.` 会清空工作目录。请使用新目录，或先备份目标目录中的内容。
:::

## 与 init 的区别

| 行为 | `create` | `init <name>` |
| --- | --- | --- |
| 交互选择模板和目录 | 支持 | 支持 |
| 默认目标目录 | 模板的 `defaultDir` | 位置参数 `<name>` |
| 填写项目描述 | 不提供 | 提供 |
| 替换 `pkg-placeholder`、`_description_` | 保留模板原文 | 替换 `package.json` 和 `README.md` 中的占位符 |
| 初始化 Git | 不提供 | 可使用 `--git` |
| 自动安装依赖 | 不执行 | 不执行 |

`create` 只声明公共选项 `-c, --cwd <dir>`，目标目录在交互提示中输入。需要描述和占位符替换时，使用 [`init <name>`](./init#从模板创建项目)。生成后进入目标目录，按模板要求安装依赖。
